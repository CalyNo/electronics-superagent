# 测试报告技能（TEST / S4）

## 何时使用

满足以下任一条件时加载：

- 消息要求"测试报告 / 试验报告 / 验证报告 / 跑测试出报告"；
- 需要为 DVP&R 条目、特殊特性或 PPAP 提供验证证据；
- 8D 的 D6 验证需要独立测试记录支撑。

不适用：试产良率与产能报告（用 TR），测量系统分析（用 MSA），过程能力（用 SPC）。

## 一、交付格式（硬要求，不得更改）

| 项 | 要求 |
| --- | --- |
| 文件格式 | **Word**：`.docx`（首选）或 `.doc`。**禁止**把 Markdown 作为最终交付件 |
| 版式来源 | 沿用企业《测试报告模板》的表格样式与页眉图文，不得自创版式 |
| 受控源 | Markdown 仅作为内容受控源与校验输入；交付前必须导出为 Word |
| 命名 | `<项目代号> <产品名称>测试报告.docx`；旁附 `<同名>.meta.yml` sidecar（含 sha256） |

> 理由：客户与质量体系按 Word 受控记录归档；Markdown 无法作为签署与 PPAP 提交件。

## 二、报告版式（固定结构）

### 2.1 页眉表单（表头）

标题：`<项目/产品>测试报告`。表头字段固定为：

产品型号、产品名称、样件数量、硬件版本、软件版本、测试部门、测试周期、签发日期、测试结果、实物照片（正/反）。

### 2.2 一、电性参数测试

| 序号 | 测试项目 | 测试条件/方法 | 测试仪器/设备 | 接受条件 | 参数记录 | 判定 |
| --- | --- | --- | --- | --- | --- | --- |

### 2.3 二、功能测试

列同上。测试项应覆盖产品实际接口与功能（如串口握手、配对、报警、参数设置、升级）。

### 2.4 签署栏

测试 / 审核 / 批准，三者均需姓名（签字）与日期。

## 三、IATF 16949 必备要素

| 要素 | 要求 | 缺失后果 |
| --- | --- | --- |
| 测试依据 | 客户规范、企业标准、DVP 条目、SC 编号及版本 | 无法证明"按什么判合格" |
| 样件身份 | 样件编号/批次、硬件版本、软件版本、数量 | 无法追溯被测对象 |
| 仪器与校准 | 仪器型号、编号、校准有效期 | 数据不可用于 PPAP |
| 判定准则 | 每项给出接受条件，逐项判定 | 结论不成立 |
| 不符合项与偏差 | FAIL 项必须关闭或取得书面偏差批准 | 不得作为通过依据 |
| 结论 | 覆盖情况、遗留问题、是否支持进入下一阶段 | 门禁无法判断 |
| 追溯 | 需求→DVP→特殊特性→测试项 | 审核问询无法自证 |
| 批准 | 测试/审核/批准签署与日期 | 非受控记录 |

## 四、填写规则

1. **序号连续**：从 1 开始，不得跳号。
2. **不编造**：实测值、Cpk、GRR、日期、型号未在输入中出现，一律写「待确认」。
3. **无数据不判定**：没有实测数据的行，判定写「待确认」，不得写 PASS。
4. **依据可查**：引用的协议/标准必须写编号与版本；引用文件放附件清单。
5. **差异如实记录**：协议与固件不一致处写入"不符合项"，不得隐去。

## 五、禁止行为

- 用 Markdown 直接作为交付件；
- 删除或重排固定表头字段与两段测试表；
- 编造测试数据或把"未测"写成"合格"；
- 用测试报告替代 TR 试产报告或 PPAP 提交清单。

## 六、导出 Word 流程

1. 按 `templates/17-测试报告.md` 生成内容受控源（Markdown），完成结构校验；
2. 以企业《测试报告模板》`.doc` 为基底，将表头字段与两段测试表内容填入；
3. 另存为 `.docx`（并可按需另存 `.doc`）；
4. 在 Word 旁放置 `<同名>.docx.meta.yml`，记录 id/type/stage/status/revision/owner/sha256；
5. 交付 Word 文件，Markdown 不入交付目录。

## 七、提交前检查清单

- [ ] 文件为 `.docx` 或 `.doc`，非 `.md`
- [ ] 表头 10 项字段齐全
- [ ] 电性/功能两表列名与顺序正确，序号连续
- [ ] 每项有接受条件与判定
- [ ] 仪器校准有效期已填
- [ ] 不符合项已关闭或有偏差批准
- [ ] 追溯关系已填（需求/DVP/SC/测试项）
- [ ] 测试/审核/批准签署与日期齐全
- [ ] sidecar 与 sha256 已生成

## 与其他技能的关系

- 需要设计验证计划：`iatf-dvp`（或模板 06）；
- 需要过程能力数据：`iatf-spc`；
- 需要测量系统分析：`iatf-msa`；
- 失败项需问题解决：`iatf-8d`；
- 需提交仓库：`repo-ops`。
