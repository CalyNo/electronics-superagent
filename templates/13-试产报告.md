## 5. 失效分析

### TR-001 虚焊

| 项 | 内容 |
| --- | --- |
| 现象 | X-Ray 显示焊点空洞 >30% |
| 分析 | 回流区温度低于设定 8°C |
| 根因 | 热电偶位置偏移 |
| 措施 | 重新校准炉温曲线，增加每日点检 |
| 验证 | 后续 50 件无虚焊 |

### TR-002 功率超差

| 项 | 内容 |
| --- | --- |
| 现象 | 输出功率 9.42 kW，低于下限 |
| 分析 | 采样电阻实际阻值偏大 2% |
| 根因 | 来料批次波动 |
| 措施 | 加严来料检验，要求 ±0.5% |
| 验证 | 新批次全部合格 |
